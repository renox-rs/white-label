# wl-hr

HR: the minimal employee record and the onboarding of new staff from the templates of their job role
([spec](../../docs/modules/wl-hr.md)). Employees, onboarding, qualifications, leave, absence cases, payroll with
the WPS file, visa cases and the final settlement (decision 0005). Other modules ask about employees only through the kernel
(`wl-kernel`), never through this crate.

The host mounts it when `client.toml` enables `hr`:

```
use renox::prelude::*;

# let _ =
App::new().module(wl_hr::WlHr::new())
# ;
```
